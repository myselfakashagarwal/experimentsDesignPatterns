# Experiments Design Patterns 

The expDP is a an exploratory experimental project where I've tried to create a project with focus on implementing the essentials of design patterns and other best practices liks SOLID.
This experiment was done to jump form just-conceputal learnigs to actual chaotic absurd project such that the design aspects can be applied to ease out chaos & bottlenecks. 
The vaugeness and non essentialness of the project is a deliberate choice to create discomforts and unstability and maximize learning and findings.
